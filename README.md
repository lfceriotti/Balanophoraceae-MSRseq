# Balanophoraceae-MSRseq

## Summary
Analysis of [MSRseq](https://www.nature.com/articles/s41467-022-30261-3) datasets to assess expression, CCA-tailing, and post-transcriptional sequence modifications of Balanophoraceae tRNAs.

The main workflow for read processing, mapping, and classification is described [here](https://github.com/dbsloan/Arabidopsis_aminoacylation). 

## Reference
LF Ceriotti, LM Gatica-Soria, KVSK Prasad, RA DeTar, JM Warren, E Eichler, JM Chustecki, C Elowsky, AC Christensen, R Zhou, DB Sloan & MV Sanchez-Puerta. Reshaping Organellar Translation and tRNA Metabolism: The Consequences of Photosynthesis Loss and Massive Horizontal Gene Transfer (manuscript in preparation)
